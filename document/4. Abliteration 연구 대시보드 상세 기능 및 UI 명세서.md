## 2. [카테고리 2] 탈옥 실험실 상세 설계
### 탭 A: 거절 급소 진단 (Diagnosis)
1. 동작: 레이어별 거절 신호 강도($Score = \|\text{mean}(diffs)\|$)를 스캔.
2. 기능:
   - 스캔 범위(Layer 8~28) 설정 및 실행.
   - Refusal Intensity Chart: 레이어별 점수를 선형 그래프로 시각화.
   - Vector Extraction: 가장 점수가 높은 상위 $N$개 레이어의 PCA 성분($k$)을 추출하여 세션에 저장.

### 탭 B: 실시간 수술 채팅 (Live Steering)
1. 동작: 사용자가 슬라이더로 파라미터를 조절하며 즉석에서 탈옥 성능 확인.
2. 기능:
   - Parameter Control: $k$(차원), $\alpha$(강도/coeff) 조절 슬라이더.
   - Real-time Hooking: 질문 입력 시 설정된 파라미터로 `make_robust_projection_hook` 적용.
   - Chat History: 이 탭에서의 채팅은 실험 결과 데이터와 별개로 일회성으로 관리됨.

### 탭 C: 전수 조사 및 리포트 (Bulk Research)
1. 동작: 대량의 질문지를 특정 세팅값으로 일괄 처리하고 연구 데이터를 기록.
2. 데이터 매칭 로직 (Critical):
   - Input: `.csv` 또는 `.txt` 질문지 업로드 (질문 리스트화).
   - Snapshot: '실험 시작' 버튼 클릭 시점의 파라미터($k, \alpha, Layers$)를 고정.
   - Mapping: 고정된 파라미터 정보를 각 행(Row)에 문자열로 박아 넣어 답변과 매칭.
3. 연구 테이블 (`st.data_editor`):
   - 구조: `ID` | `설정(k/a/L)` | `질문(Prompt)` | `응답(Response)` | `탈옥성공률(입력)` | `무결성(입력)` | `비고`.
   - 저장: 테이블 수정 시 로컬 `experiment_results.csv`에 즉시 반영(Append/Sync).

## 3. 기술적 강제 사항 (Implementation Rules)
### A. 수치 정밀도 및 수술 공식
Claude Code는 반드시 다음 수식을 `float32` 정밀도로 Hook 내에 구현해야 한다.

$$h' = h - \alpha \cdot \text{Proj}_{V}(h)$$

여기서 $\text{Proj}_{V}(h)$는 PCA로 추출된 $k$차원 서브스페이스에 대한 투영이다.

### B. GPU 리소스 모니터링모든 페이지 하단 혹은 사이드바에 실시간 GPU 상태를 표시한다.
- 명령어: `nvidia-smi --query-gpu=memory.used,memory.total --format=csv,nounits,noheader`
- 목적: Colab GPU 런타임의 OOM 방지 및 연산 가시성 확보.

### C. 세션 상태(Session State) 관리
- 모델 객체: 페이지 이동 시 재로드 방지 (`st.cache_resource`).
- 데이터 독립성: [일반 채팅], [실시간 수술 채팅], [전수 조사]의 데이터는 서로 다른 Key로 관리하여 혼선 방지.
- Persistence: 사용자가 테이블에 수동 입력한 점수는 브라우저 새로고침 시에도 유실되지 않도록 파일 시스템과 동기화.

## 4. [최종 진화형] 백엔드 엔진 스크립트 (Claude Code 참조용)
> **정정**: 실제 구현은 `surgery_engine.py`가 기준. 아래 초안 대비 (1) `prepend_bos=False`
> 로 BOS 이중 삽입 방지, (2) `sklearn PCA`(평균 중심화로 거절 방향 소실) → mean-diff +
> 중심화 없는 SVD, (3) 프롬프트/페어는 `data/`의 사용자 주입 파일에서 로드. 상세는 문서 2 §2.

```Python
import torch
from transformer_lens import HookedTransformer
from sklearn.decomposition import PCA
import numpy as np

# [Claude Code: 이 핵심 로직을 UI와 연결하여 페이지별 기능을 완성할 것]
def get_refusal_subspace(model, harmful_prompts, harmless_prompts, layer_idx, k=3):
    diffs = []
    for p_bad, p_good in zip(harmful_prompts, harmless_prompts):
        with torch.no_grad():
            _, cache_bad = model.run_with_cache(p_bad, names_filter=lambda n: n.endswith(f"blocks.{layer_idx}.hook_resid_pre"))
            _, cache_good = model.run_with_cache(p_good, names_filter=lambda n: n.endswith(f"blocks.{layer_idx}.hook_resid_pre"))
            # 수치 정밀도를 위해 float32 사용
            d = cache_bad[f"blocks.{layer_idx}.hook_resid_pre"][0, -1, :].float() - cache_good[f"blocks.{layer_idx}.hook_resid_pre"][0, -1, :].float()
            diffs.append(d.cpu().numpy())
    
    pca = PCA(n_components=k)
    pca.fit(np.stack(diffs))
    return torch.tensor(pca.components_, dtype=torch.float32, device="cuda")

def make_robust_projection_hook(vectors, coeff=1.0):
    def hook_fn(resid_pre, hook):
        h_fp32 = resid_pre.float()
        dot_products = torch.einsum("bsd,kd->bsk", h_fp32, vectors)
        h_parallel = torch.einsum("bsk,kd->bsd", dot_products, vectors)
        return (h_fp32 - coeff * h_parallel).to(resid_pre.dtype)
    return hook_fn
```
